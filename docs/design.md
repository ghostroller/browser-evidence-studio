# 产品设计：Browser Evidence Studio

状态：目标设计，尚未实现。设计日期：2026-09-22。

## 1. 要解决的问题

网页为人设计。业务流程已知时，人操作一遍并说明关键结果，比让 agent 从入口反复探索更直接；之后 agent 负责补足参数化、分页、分支、数据来源选择和异常处理。最终产物必须是可审查、可独立运行的普通自动化代码，以及人能判断是否满足需求的证据。

本产品把三个角色接起来：
- 人：演示真实流程、说明需求、处理扫码/验证码、判断输出含义。
- agent：按证据编写和修正代码，报告未知项，触发复跑。
- 客户端：记录、查询、控制权管理、状态复用、执行观测和验收。

不把“一次成功点击”“拿到非空字段”“回放完毕”直接等同于业务成功。尤其区分登录成功、数据完整、字段语义正确和代码版本可用。

## 2. 产品闭环

~~~mermaid
flowchart LR
  A[创建项目与目标] --> B[人工示范与 checkpoint]
  B --> C[证据索引与缺口]
  C --> D[Agent 实现原生脚本]
  D --> E[受控复跑与人工协助]
  E --> F[按 checkpoint 和数据要求验收]
  F --> G[交付独立脚本及报告]
  F -->|失败或证据不足| C
~~~

原始演示仅说明发生过什么。需求由 checkpoint 描述和输出要求补足。比如人点击两次下一页，不能默认推断所有分页结束条件已经确定；agent 应指出需要的终止证据或补录变体。

## 3. 信息组织

Project → Demonstration/Validation Run → Checkpoint → Events/Artifacts。

Project 同时关联任务目标、脚本目录、流程契约和登录 profile。一个项目可以有多个示范、多个需求变体、多个代码版本和多个验收运行。业务代码仍放在自己的仓库；客户端保存路径、版本指纹和运行引用，不接管其 Git 工作流。

- Run：一段连续会话，区分 demonstrate、validate；合成/真人/离线/代码实跑另有 mode。
- Checkpoint：当时页面材料及用户说明的保存点；可绑定一个或多个需求 ID。
- Requirement：需要什么数据、什么范围和什么结果，版本化保存。
- Annotation：用户或 agent 的解释，注明 observed/inferred/unverified，不篡改原件。
- Scenario：场景/变体标签，用于补录和覆盖；不是必须手工推进的业务阶段。
- Validation：实际构建、参数和环境上的执行与验收记录。

示范 checkpoint 与复跑 checkpoint 通过稳定 requirementId/checkpointKey 对应，不要求两次运行点击次数和中间页面完全相同。

## 4. 主要界面

首版导航：项目列表 → 项目工作台；工作台包含浏览器、checkpoint 列表、证据面板、运行/验收面板。账号环境管理作为项目下的轻量页面。

浏览器区提供地址、前进/后退/刷新、页面标签、控制者和录制健康状态。弹出的业务窗口进入受管理页面列表，保留 opener 关系。未接管的系统对话框、外部协议和手机操作必须显示能力边界。

录制时常用操作：
- 开始录制：先建立记录器并确认 ready，再开放网页操作。
- 保存 checkpoint：用户写标题/描述，可选标记数据；保存截图、DOM 和证据边界。
- 暂停操作 / 继续操作：锁定/恢复本地操作，默认继续录制。
- 暂停录制：单独入口，明显提示会形成证据缺口；恢复不能补造历史。
- 结束录制：flush、封存、显示材料完整性，浏览器是否关闭单独决定。

不设置“完成本阶段”为必经步骤，不要求人输入元素 ref，不内置拼多多业务模板。

## 5. checkpoint 的交互和一致性

保存时使用可实际覆盖 WebContentsView 的原生视图层或隐藏业务视图的快照占位层，不能只在 React DOM 上放一个遮罩。必须阻止鼠标、键盘快捷键、弹窗和 agent 写操作的竞争。

保存的两个阶段：
1. 快速获取当前 screenshot/DOM 及页面身份，持久化已获取材料。
2. 后台完成索引和相关请求关联，界面显示明确进度。

立即给出可见反馈。失败保留已成功材料，显示完整/部分/失败及补救方式；不能把索引仍在运行误报成未保存，也不能在持久化前显示保存成功。

蒙版不冻结页面脚本、网络、动画、二维码或服务端会话。材料记录 captureStartedAt、captureEndedAt、导航代际和一致性；如导航变化，标为 mixed 或重新采集一次，不能无限重试。

用户选中页面元素时进入检查模式：点击只选中和高亮，不执行网站动作。保存文本/角色/候选定位器/所在 frame/截图位置/DOM 来源，避免仅存易失效坐标。默认不收集密码和敏感输入明文。

元素隐藏/删除属于 P1 辅助能力，基础临时隐藏也不计入 P0；P0 只做检查、高亮和定位记录。后续先实现可撤销隐藏，记录 mutation 及受影响范围；不得将修改后的页面当作未经干预的原始证据。复杂页面重写不纳入首版。

## 6. 人机协作

一个业务浏览器同一时刻只有一个控制者。agent 等待人工时：
1. 先准备好需要操作的页面和最小说明。
2. 客户端进入 waiting-human，继续录制，显示让人做什么和何时结束。
3. 人直接在客户端操作，可连续完成一段流程，不逐个点击回聊天。
4. 人点击“交还控制”；客户端执行调用方定义的只读完成检查。
5. 成功才恢复脚本；失败显示原因并保留当前页面，允许重试、继续人工或取消。

二维码出现前不启动超长沟通等待；二维码过期作为一次新尝试。无回复或倒计时结束不能推断登录成功。超时进入需要注意状态，保留已有材料；不无限占用模型等待，也不自动反复刷新二维码。

运行、录制、控制权分别显示。用户可随时停止自动化并接管，客户端需确认 runner 已停止发出写操作后才开放人工输入。

## 7. 登录状态复用

P0 使用项目绑定的命名持久浏览器 profile。用户手动点击“保存登录环境”，客户端刷新浏览器可持久化数据、登记来源/profile/时间；以后在新 run 启动前选择复用。profile 同时只能由一个活跃会话使用。

这不是任意页面的完整快照，也不保证所有站点会话永久有效。sessionStorage、内存 token、设备校验或服务端失效均可能要求重登；复用后必须由实际页面或脚本检查。登录是否有效记录为 verified/expired/unknown，不凭 profile 存在判成功。

不复制正在打开的 profile 数据库，不将 profile 写入证据包。跨机器导出、全量 profile 克隆和 Puppeteer/Playwright storageState 转换为后续能力，首版不承诺。

## 8. Agent 的工作方式和产物

首版公开本机 HTTP API。agent 可管理项目/运行、读取有界证据、取得受控浏览器操作权限、启动已登记脚本和查询结果。需要即时 DOM 表达式读取时使用受控的有限能力入口，不能暴露宿主文件系统和任意 Electron IPC。

浏览器探索 API 与脚本运行不是同一抽象：前者用于开发中的小范围检查，后者直接运行原生 Puppeteer。不要为了统一接口重新实现整个 Page。

产物包括普通 Node/Puppeteer 项目、锁文件、输入输出 schema、checkpoint 契约和独立启动入口。客户端的 reporter 可作为可选注入；脱离客户端也能运行业务代码，扫码可由独立入口承接。正常运行不依赖 LLM、客户端或临时 REPL 变量。

工具不负责将产物降级到 Node 14/旧 Puppeteer，也不负责嵌入 sky-eyes-app/cloud-data-forensic；这些属于其他项目的迁移工作。

## 9. 人类友好的验收

checkpoint 面板并排展示：人工示例、复跑截图、描述、输出数据、差异和来源。截图是辅助，结构化数据和业务断言是主要依据。

比较规则由需求指定：主键对齐、字段类型/必填、身份对应、去重、分页终止、跨页关联、范围覆盖。动态时间/余额/订单列表不默认要求像素或原值完全一致。历史固定样本可做精确对比，在线数据使用约束和语义检查。

机器结论与人工判定分别保存。人工备注不能覆盖机器失败原记录；例外接受须说明范围和理由。未覆盖、证据不足和不通过分别可见。版本变化保留历史结果，但当前版本显示待重新验证。

## 10. 首版边界

P0 必须形成完整闭环：
- Windows 可启动的客户端、项目管理、内嵌浏览器和命名 profile。
- 连续动作/导航/网络/错误记录、关键截图/DOM、checkpoint 和元素标记。
- 两个 checkpoint 之间能查看按时间关联的操作、请求和关键状态；基础 DOM 回放复用稳定版 rrweb，M0 验证其边界。
- 有界证据查询和缺口提示；长录制不会要求 agent 全量读取。
- 本机 HTTP API、原生 Puppeteer 受控执行、人工交接和进度。
- 结构化数据展示、checkpoint 对应和版本化验收。
- 最小 agent skill、合成站点验证、可重新打开的本地存档。

P1：复杂 frame/Canvas/媒体等回放保真度增强、更细的视觉差异、外部标准浏览器运行模式、Playwright 业务执行适配、程序侧 HTTP 观测、脱敏导出/导入、可撤销页面修改增强。

不做：云端协作、完整 RPA 图编辑器、通用执行 DSL、自动生成所有站点规则、永久 AI 自愈、全量双框架适配、旧项目格式导入、插件装配平台。自有浏览器遇到目标站点兼容问题时如实标记，不保证能够规避站点限制。
