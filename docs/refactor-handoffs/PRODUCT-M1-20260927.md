### 可运行入口

- `npm run build`：开发构建，非发行打包。
- `npm run demo:product`：启动常驻合成站点和普通可见 Electron，每次创建全新 `output/product-demo-<时间>` 空 BES_DATA；控制台给出 `/orders` 入口。登录环境、项目、录制与资料全部从正常 UI 建立，启动器不预建业务对象。站点只处理合成登录和两条订单。
- `npm run demo:product -- --handoff=<UI导出的交接目录> --output=<实现目录> --source=<合成站点/orders>`：明确标记的演示实现器，通过交接的 manifest/access 与正式有界 HTTP 读取固定资料，只写普通脚本、workflow、lock 与 implementation.json。没有资料写权限、不会改字段含义。然后用户正常登记目录、读取并确认映射、固定新版本。
- `npm run test:journey`：新空 BES_DATA 上连续原生 UI 输入，两个 Electron 进程。主阶段覆盖 U01–U06；第二阶段真实重启、恢复字段绑定/历史节点/固定 hash。只读诊断不补写业务状态。保存全部失败记录。
