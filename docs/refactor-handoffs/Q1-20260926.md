## 变更

- N01：`CaptureCoordinator` 在真实 CDP `responseReceived` 回调同步取得宿主时间；`RequestLedger` 保留每个 request/occurrence/hop 的页面、录制、导航、frame/loader 及请求开始身份。延迟读取、失败、隐私排除等响应正文路径从原请求对象写入来源。`ProjectExecutions.assess` 要求 `recordingId/pageId` 一致，请求开始与响应观测都处于实际 attempt 范围；缺失时间或旧版缺身份不回填为成功。
- N04：checkpoint DOM 过滤 `srcdoc` 和内联脚本，实时 snapshot 对 `.rr-mask`、`.rr-block`、表单及私有后代遮罩，URL 经过采集元数据隐私处理。截图原始字节保持完整，新增 `capturePrivacy.access=restricted` 标记；普通 Agent `/content` 对所有 `screenshot`（包括旧未标记记录）及其他 restricted 材料拒绝，可信 UI 显式通道继续可读。没有宣称 PNG 像素已脱敏。
