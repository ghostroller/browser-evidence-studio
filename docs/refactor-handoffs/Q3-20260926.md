# Q3 固定任务交接与公开接口

日期：2026-09-26。集成点：主树 `main`，Q2 基线 `25b7baa`；本记录随 Q3 实现提交。按用户要求在 Q3 复盘点暂停，Q4–Q6 未启动。

## 已实现

- 可信 React“任务授权与撤销”界面选择已发布的资料 revision、当前有效授权，点击“准备交给 Agent”。导出只经可信 UI；`handoff-export` 加 `materials-read`、项目、目录、revision/hash、连接路径和撤销状态均在服务端核验。
- 原子保存 `task.md` 与 `manifest.json` 到当前数据根 `projects/<projectId>/handoffs/<uuid>/`。文件固定 project、revisionId/contentHash、结构化需求/字段/历史位置及当前实例与授权范围。task 最大 32 KiB、manifest 最大 64 KiB；不复制 Bearer、Cookie、profile、截图像素、原始 DOM/响应或自由文本。`taskSha256` 可核对文件；旧 V1 不随 V2 发布改写。
- 新任务通过交接里的连接文件路径与授权 ID 核对 `/health.instanceId`，再用公开 API 读取 scope 内的 state、固定资料及有界历史节点，建立候选资料、读取 diff/taskChanges、启动固定版试跑和结果读取。实例 health 与交接共用 `studio.instanceId`，不要求从受保护 state 猜授权 ID。
- `POST /v1/runs/:runId/pages` 按 `page-create`、当前 session/profile/page/generation/lease、授权来源域创建后台页；页面登记进入授权范围。后台页快照与受控 action 不改变前台选择。隐藏原生页的 Puppeteer 可见性等待曾超时；现仅在页面实际参与合成时执行目标页鼠标输入，测试回读按钮计数确认动作发生。若覆盖层使页面无法呈现，点击明确失败，不把空操作报成功。
- 项目级 skill 增加固定交接指引和 API 入口；`docs/api.md` 同步路由与交接流程。skill 未安装到全局，发行包内的路径/静态资源仍由 Q5 验证。
