## 实现与边界

- N02：生产 ReplayHost 的播放准备使用命令代际和意图校验。准备期间的暂停、seek、切流、关闭会使旧播放失效；React UI 忽略迟到状态。保留原生 Replayer 连续播放，未改成逐事件重建。
- N03：请求台账保持 request/hop、frame、响应完成、cache 和 Service Worker 来源。离线解析区分 DOM 使用时间、具体请求版本及字节可用时间；晚完成资源只在已有记录的后续位置激活。同 URL 两版 CSS、跨源 CSS/图片/字体、重定向、延迟图片、CSS 依赖、缓存、Service Worker 资源及 blob 均由生产录制再离线消费。仅对有界、签名匹配的原始 `data:` 图片/字体字面值放行；其他格式保留诊断，不联网填补历史。相同毫秒的使用与完成按保守延迟激活，不能读取未来字节。
- N05：增量 style 文本走同一 CSS 资源改写；多文档前台转换从录制事件读取，保留来源缺口和显式空闲段，UI 跟随真实前台流；回放空页面使用惰性 `about:blank`，视口按录制尺寸适配。源属性仍来自采集，不从回放 DOM 伪造。
- 旧完整桌面矩阵对齐现行任务授权：测试通过可信 UI 签发范围授权、覆盖撤销和工作归属；固定任务 worker 的完成只证明执行完成，没有来源证明的机器评估保持 `inconclusive`，不能伪称需求通过。测试夹具对齐当前 ReplayHost UI；未恢复退休的一次授权或裸 lease。

跨源 iframe 的 DOM/source 仍标为 `unsupported`，其可独立捕获的 CSS/图片/字体不等于可读取该 frame 的 DOM。旧档缺请求时序只能报告能力下降。尚未验证不同物理 DPI/zoom 的命中一致性、新格式 30 分钟负载或安装包。
